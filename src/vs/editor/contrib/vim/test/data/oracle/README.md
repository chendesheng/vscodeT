# Vim reference cassettes

Generated by `scripts/oracle/record_nvim.py` from a pinned Neovim build
(`NVIM v0.10.4` for the initial corpus). Each JSON file is one scenario:
seed text/cursor, key tokens, and the states recorded from Neovim.

Replay with:

```sh
zig build test-oracle
```

Record or refresh:

```sh
scripts/oracle/setup.sh
scripts/oracle/record_nvim.py --all
scripts/oracle/record_nvim.py --check --all
```

v1 covers ASCII documents, a single cursor, and final `normal`/`insert`/
`replace` modes. Visual ranges and registers are not asserted yet.
