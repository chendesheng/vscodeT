# Vim reference cassettes

Generated by `scripts/oracle/record_nvim.py` from a pinned Neovim build
(`NVIM v0.10.4` for the corpus). Each JSON file is one scenario: seed
text/cursor, key tokens, and the states recorded from Neovim.

Replay with:

```sh
zig build test-oracle-vim
```

Record or refresh:

```sh
scripts/oracle/setup.sh
scripts/oracle/record_nvim.py --all
scripts/oracle/record_nvim.py --check --all
```

The corpus covers ASCII documents, a single seeded cursor, and final
`normal`/`insert`/`replace` modes. Each cassette records `height` (the visible
text rows; the recorder sizes the Neovim window to it) and the viewport
`scroll.top_line`/`scroll.left`. The replay asserts text, mode, cursor and
scroll. Visual selections are not a recorded final mode; register contents are
checked through their resulting text rather than as raw register state.
