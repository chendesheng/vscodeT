# VS Code built-in extension status

The native TUI targets **87 of the 94 shipped desktop extensions** in VS Code 1.147.0. Seven packages are deferred. Copilot inline completions are in scope. Debugging, profiling, notebooks and chat are deferred, including those contributions inside otherwise in-scope packages. [Desktop packaging rules][packaging] · [Product package list][product]

Implementation and local verification on 2026-11-24 and 2026-11-25, against VS Code pin `e31c2e52f563620846caab877103f630ea361b9c`. Installed terminal checks below ran on macOS. Linux and Windows verification is pending.

| Status | Packages | Meaning |
| --- | ---: | --- |
| Verified | 0 | All scoped workflows passed in the installed TUI on the target platforms, with recorded evidence. |
| Partial | 87 | An identifiable portion is wired. The row gives the working path and the remaining integration or verification. |
| Planned | 0 | The package is in scope and a required integration is missing. |
| Unverified | 0 | Evidence is insufficient to classify current behavior. |
| Deferred | 7 | The entire package is outside the current scope. |

The native install includes all 87 in-scope manifests. Startup scans its own installation directory, resolves TextMate includes and injections, applies language editing rules and registers contributed snippets and color themes. `zig build host` installs the optional executable packages. Windows still needs an extension-host transport. [Startup wiring][startup] · [Host transport][transport]
